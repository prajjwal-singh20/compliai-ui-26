CompliAI – Indian Startup Compliance Copilot

CompliAI helps early-stage Indian founders understand what legal compliance they actually need — without reading 200 pages of MCA or GST documentation.

Built during a hackathon to make compliance feel like a product, not paperwork.

🚩 The Problem

Indian startup compliance is confusing.

Founders struggle with:

Choosing the right company structure

Understanding GST and other registrations

Knowing what documents they need

Tracking risk and compliance status

Most early founders either ignore it or overpay consultants.

💡 The Solution

CompliAI turns compliance into an interactive dashboard.

You answer a few basic questions about your startup.
It generates:

Recommended entity type (OPC vs Private Limited)

Tailored registration checklist (GST, IEC, Shops & Establishment)

Required documents

Risk alerts

A simple compliance score

Everything updates dynamically based on your inputs.

✨ Key Features

Founder-friendly question flow

India-focused rule engine

Dynamic compliance score

Animated dashboard UI

Built-in Copilot chat (rule-based, context-aware)

Clean dark-themed interface

🛠 Tech Stack

React 18 + Vite

JavaScript

Custom CSS (no UI frameworks)

Designed to plug into Express + Mongo later
